# 再往前十秒 · 独立调查 demo

这是《再往前十秒》M01–M08 的可独立试玩浏览器短篇。玩家用有限历史节点重建事故，核验报告与证言，再用同一套时间控件保留一个私人生日片段。案件提交与私人保存是两项独立动作；没有有罪／无罪、道德评分或强制原谅。

## 安装与运行

需要 Node.js 22.12+（本次实际使用 Node.js 24.19.0）。所有依赖和配置都在此目录。

```bash
cd 02-ten-seconds-earlier/demo
npm ci
npm run dev
```

浏览器打开 `http://localhost:5172`。覆盖端口：`npm run dev -- --port 5182`。

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

生产预览默认同样使用 5172；覆盖端口：`npm run preview -- --port 5182`。运行时只有本地资源，无 CDN、外部搜索、遥测、账号或后端。首次安装开发依赖需要包管理器网络；安装完成后游戏可离线运行。

## 浏览器验收

```bash
# 本环境已有 /usr/bin/chromium，直接使用
npm run test:e2e

# 其他环境先准备 Chromium，再指定可执行文件
CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e
```

没有系统 Chromium 时也可用 `npx playwright install chromium` 安装，配置会自动使用该浏览器；无需填写 `CHROMIUM_PATH`。本项目不把浏览器或构建产物提交到 Git。

E2E 自动构建生产版本并在 5172 启动 preview，请先停止占用该端口的 dev/preview 服务。测试以真实 UI 完成两条 M01–M08 路线；完整路线不注入进度、不使用开发跳关。自动生成的报告、trace 和失败截图位于被忽略的 `playwright-report/`、`test-results/`。少量交付截图位于 `artifacts/screenshots/`。

## 完整试玩流程（含剧透）

1. 新建调查，接受事故与私人生日两个独立范围。
2. 查询事故夜，从 21:16:30 播放或逐秒至 21:16:40，收集隔离闸控制动作，归为“行为事实”。完成现场调查进入 M03。
3. 查询四十天前，核验 R-17 原件（当时掌握的信息）、修改版（行为事实）与签字现场（当时掌握的信息）。查询应急效果，至 21:16:58 核验减灾窗口与未执行核查（后果与核对资料）。这三个节点可交换访问顺序，重复访问不重复生成证据。
4. 完成现场调查，先接受许宁“仅事故相关时间点与应急效果”的许可，再收集、归类证言（后果与核对资料）。没有许可就不能录入；私人语音全文不出现在包中。
5. 核对摘要，唐雯主动出示回执。选择回应，再确认独立家庭检索授权。
6. 正式录像起点为 18:30:00；精确回退十秒到 18:29:50，播放或逐秒看完伸手、拦住、移碗、吹气、给回勺子。观察片段来自授权历史观察，并非相机原片的恢复。
7. 定下这十秒，分别提交案件与确认私人保存。两者可以交换顺序。“爸爸”只给唐雯，不附在案件中。
8. 走到门口。可以再听一次、暂停、逐秒看、回到工作台查看两份文件。保存不表示她原谅父亲，也不替她决定探视。

缺线索会显示具体名称、来源节点和所需操作，不因情感回答而锁住流程。三个回应都有不同的可见答复，没有正确的“善良”选项。

## 操作与存档

鼠标、原生按钮触控、Tab / Shift+Tab 导航、Enter / 空格激活均可操作。历史画面有前一秒、后一秒、精确退十秒、播放／暂停和逐秒时间轴。焦点不在输入框时，← / → 逐秒、R 退十秒；焦点不在按钮或输入控件时，空格播放／暂停。无需精确拖拽或快速反应。

体验设置提供静音、关闭打字、减弱动态；字幕始终可读。环境音由本地 Web Audio 产生，无语音配音。减弱动态停用装饰动作，关键时间动作仍由玩家逐秒决定。

存档仅使用 `sci-fi-games:02-ten-seconds-earlier:v1`，每次有效操作自动保存。刷新后点“继续调查”。重开需原生确认，只覆盖本故事。损坏或不兼容存档明确提示，可以新建恢复；不会清除其他故事的数据。播放在恢复时暂停。浏览器限制存储时显示失败提示，仍可完成当前体验。

## 实现与素材

- `src/content.ts` / `src/presentation.ts`：稳定场景、对白、证据、来源、时间节点和许可文本。
- `src/state.ts`：显式门槛、归类核验、两条资料链、幂等提交、存档校验与恢复。
- `src/scenes.ts`：统一原创 SVG 空间、人物与物件动作。控制室两时段共用图形，呈现日程、照明、报告、门体变化。
- `src/main.ts` / `src/style.css`：DOM 调查桌、字幕、时间控件、文件查看、焦点与窄屏布局。
- `tests/state.test.ts` / `e2e/game.spec.ts`：状态与真实生产浏览器验收。

仅 Vite、TypeScript、tsx、Playwright 为开发依赖。无通用游戏引擎。画面、音色和新增对白为本 demo 编排，不包含原著全文、影视或商业游戏素材。不新增整体内容许可证；作品改编授权／未来发行仍按仓库原文另行处理。

真实验证与局限见上级 `PLAYTEST.md`。没有进行真人用户研究，不宣称达到原文 25–35 分钟目标时长。
