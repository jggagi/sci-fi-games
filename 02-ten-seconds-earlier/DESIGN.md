# 《再往前十秒》设计说明

## 玩法与叙事的同一个动作

前面倒回时间，是为了确定责任；后面倒回同样十秒，是为了保留一个不抵消责任的生活片段。关键控件必须完全复用，不在结尾换成无法操作的动画。

玩家调查的是动作、当时可获得的信息、材料改变和后果。观察器不生成『好人／坏人』标签，不把推测写成事实。第一版使用精心编排的有限查询节点，而不是承诺可查看宇宙中任意地点。

## 伏笔

| 线索 | 初见理解 | 后见意义 |
| --- | --- | --- |
| M01『还有事故之前』 | 女儿替父亲寻找借口 | 她主动要求追查前期失责 |
| M01匿名原件编号 | 案件起始线索 | 与她主动拿出的回执相同 |
| M03『原版也放进去』 | 在意材料齐全 | 她从未要求隐去责任 |
| 私人生日检索单独列出 | 想用温情包装父亲 | 她本来就没有要求将其当成免责证据 |
| 正式录像的起始时间 | 普通时间轴定位 | 真正想留下的动作在录像开始前 |
| 受害家属要求事实完整 | 阻碍父女和解 | 为双重真实奠定不偏袒的基线 |

唐雯身份由她主动披露。不存在必须侵入保密信息才能解锁的谜底，也不能让叙述者先断言她无辜不知情。

## 状态与证据

- `sceneId`、`queryHistory[]`、`activeTimeAnchor`、`playheadOffsetSeconds`。
- `evidenceSeen[]`、`evidenceVerified[]`；每项有固定 ID、来源、时间、许可范围和事实类别。
- 核心证据：`gate_action`、`original_warning`、`amended_report`、`signature_scene`、`mitigation_timeline`、`witness_statement`。
- `sourceReceiptDisclosed`仅由 M05唐雯主动给出设置；不是从私人场景暗中获取。
- `birthdayRangeAuthorized`、`privateSegmentStart`、`privateSegmentEnd`、`privateExportConsent`。
- `caseSubmitted`和`privateClipSaved`相互独立，任一不能自动完成另一个。
- `exportName`规范结局为『爸爸』。案件包无私人片段；私人包无案件或其他人的敏感资料。

事实核验可以有正确／错误反馈；对情感、探视或原谅不评分。缺证据要提示具体遗漏，不能靠『情感选择错误』锁住进度。

## 空间与素材范围

三个主空间：工作室、可切换时段的控制室、家庭餐桌。许宁用简洁视频／文字通话表达。事故只用结构图、时间线和控制台，不做伤害特写或现场惨叫。家庭十秒需要克制但清晰的动作：儿童伸手、父亲挡住、拉近碗、吹气、交回勺子。

时间控件提供键盘加减一秒、精确退十秒、播放暂停。语音都提供字幕；暂停时关键线索文字可读。档案长文本分层显示，不强迫玩家读几十页法规。

## demo 路径

M01 → M02 → M03 → M04精简证言 → M05 → M06 → M07 → M08。保留父亲减轻当晚损害与前期失责两面；不能把他简化成纯恶人来让反转更容易。

最低两次真实调查操作、一次证据归类、一次主动授权确认、一次十秒回溯、两个独立导出和一次余韵重播。目标25–35分钟，不做随机证据海或开放世界搜房。

## 风险

- 不能通过童年温情洗白事故责任。
- 不能让遇难者家属替唐雯背书或承担安慰任务。
- 唐振声活着，关系未来不由制作人员表替唐雯决定。
- 不把『我选择不再接触父亲』写成失败；故事允许想念与保持距离并存。
- 生日十秒来自授权的历史观察，不谎称实际家庭摄像机拍到了录制前的片段。
- 无论观察器多强，对人物内心的推测仍要保持推测身份。

## 试玩验收问题

玩家能否分别复述唐振声做过的应急行动与前期失责？是否发现唐雯从未要求删证据？身份揭晓有无让前面的行为获得新解释？最终两个文件各自保存了什么？玩家是否误以为必须原谅或赦免？

最重要的失败信号不是没哭，而是『只要他曾是好爸爸就不用负责』或『揭发以后就不该想念』。出现这种理解，先调整因果与角色对白。
