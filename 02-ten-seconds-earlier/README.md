# 再往前十秒

> v0.1 · 2026-10-03 · 开发剧透文档 · 平行改编构想

背景起点：《镜子》。本篇把历史观察能力放进一宗虚构事故调查；案件、人物、访问制度与对白均为新增。

**一句话：她亲手举报了父亲，却仍想找到一段可以只叫他爸爸的记忆。**

## 人物

- **林澈，玩家角色**：独立事故重建员，擅长找事实，容易以为事实清楚以后感情也应该清楚。
- **唐雯**：事故责任人之女，也是最初的匿名举报人。不是等待被玩家揭穿的撒谎者；她从未要求删除不利证据。
- **唐振声**：她的父亲，参与压下风险报告，事故当晚也实施过真实的应急救援。他仍然在世；本篇不靠临终病逝强迫和解。
- **许宁**：遇难者家属，提供自己有权提供的材料。她不是证明父亲有多坏的工具，也不需要替唐雯原谅谁。

## 不可替换的情感闭环

机器能显示真实过去，但不能替人判定该怎样爱、怎样承担责任。调查确认父亲的失责；举报人身份揭晓，重新解释唐雯一直没有阻止调查的行为。最后把生日录像的起点往前移十秒，只看到父亲拦住小孩去拿热碗：『烫，等一下。』

完整证据进入案件材料；私人十秒在她同意后单独保存，文件名叫『爸爸』，不叫『他其实是好人』。这两个操作不能相互抵消。
