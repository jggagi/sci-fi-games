## 环境与实际命令

Node.js 24.19.0、npm 11.9.0、Vite 7.3.6、TypeScript、Playwright、系统 Chromium，中文字体可用。

在 `02-ten-seconds-earlier/demo/` 实际执行并通过：

```bash
npm install --cache /tmp/ten-seconds-npm-cache --no-audit --no-fund
npm run typecheck
npm test
npm run build
npm run test:e2e
```

首次开发安装与浏览器测试的本地端口监听，在本托管环境需命令执行工具的网络权限；沿用环境代理与 CA，没有绕过网络策略。原 `tsx --test` CLI 创建 Unix socket 在沙箱被拒绝，现用 `node --import tsx --test --experimental-test-isolation=none tests/*.test.ts`，18 个测试均实际执行，无删减。交付前另下载官方 Node.js 22.12.0 至临时目录，确认其不支持新拼写 `--test-isolation=none`，改用兼容两版本的旧拼写；该等效命令在 Node.js 22.12.0 上实际执行并通过全部 18 个状态测试。未在旧 Node.js 上重跑生产构建或 E2E。

`test:e2e` 自动运行 `npm run build` 与 `npm run preview -- --host 127.0.0.1 --port 5172 --strictPort`，所有测试针对生产 bundle。配置优先 `CHROMIUM_PATH`，其次已存在的 `/usr/bin/chromium`，否则使用 Playwright 安装的 Chromium。试玩运行命令见 [demo/README.md](demo/README.md)。

## 真实浏览器路线

最终冻结源码执行结果：**5 passed (39.8s)**。

1. `production UI journey M01–M08`：11.0s。空存档，经事故夜→四十天前→应急效果，六项核验、许宁许可、唐雯披露、十秒、案件先提交、三次刷新、私人保存、余韵重播与两包核对。
2. `complete keyboard journey`：15.9s。全程真实键盘操作；应急效果→四十天前→事故夜；另一种摘要、保持安静回应；私人先保存，再案件提交，静音余韵。
3. `corrupt save recovery and restart confirmation`：906ms。此专例故意写损坏字符串及另一故事哨兵，验证恢复、重开取消和确认；完整通关路线没有注入状态。
4. `real playback ticks, pause holds, and R rolls back`：6.3s。实际自动计时播放，暂停跨过一次 tick 保持画面，R 精确退十秒；错误归类提示和核验后的焦点。完整路线还新增断言：点击余韵重播后 150ms 仍处于 18:29:50，首帧不会被先前计时器相位吞掉。
5. `narrow screen touch`：1.4s。390×844 触控、排版、时间按钮焦点与本地资源。

这些是快速自动操作耗时，**不是玩家的游玩时长**，不能据此宣称达到原文 25–35 分钟目标。

## 未验证与已知局限

- 没有真人不打断试玩、阅读时长、理解访谈或情绪反馈。不能声称玩家已经正确理解双重真实；需要按 DESIGN 的开放问题进行后续真人走查。
- 浏览器验收限定 Linux Chromium。Firefox、Safari、实体 Android／iOS、系统屏幕阅读器、不同设备音频实际听感未验证。
- SVG 为统一原创纸艺式 2D 演出，环境音是简单本地音色，无真人配音。有限历史节点服务本篇，不支持自由文本搜索或任意宇宙查询。
- 本地存档依赖浏览器存储权限；禁用时会显示错误并允许当前体验继续，但无法保证刷新恢复。跨设备同步没有实现，也不属于范围。
- 这是虚构调查制度与科幻设定的平行改编 demo，不是现实法律程序说明；授权与发行状态仍按仓库原文待另行处理。未公共部署、未自动合并。
