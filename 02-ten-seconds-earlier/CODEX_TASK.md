# Codex 任务｜《再往前十秒》调查与私人记忆 demo

## 任务

完整阅读根目录 `AGENTS.md`及本目录三份叙事文档。检查已有代码；只在本项目创建或修改 `demo/`，实现可独立运行的浏览器2D调查短篇。不只搭一个档案 UI，也不只制作生日结尾动画；从 M01到M08要可连续体验。

## 必须实现

1. 有稳定查询节点的历史观察界面，地点与时间明确。支持播放暂停、键盘前后一秒、精确回退十秒。
2. 控制室两个时段的资产复用、至少六项固定来源证据，以及事实／信息／后果的整理方式。先用可测状态和明确提示，不建设任意自然语言搜索。
3. M04简洁的受害者家属证言与许可范围；M05由唐雯主动披露回执。
4. 私人家庭场景，复用原来的时间控件定位录像前的十秒；至少包含伸手、拦住、移碗、吹气、给回勺子的清楚表现。
5. 案件资料包与私人片段两个独立导出状态。默认用游戏内虚拟文件，不读取或上传玩家真实文件；可选下载仅由玩家显式点击触发。
6. 导出后仍可重播十秒的余韵。没有有罪／无罪按钮、道德分数或强制原谅结局。

## 工程边界

默认本地浏览器、中文、鼠标／键盘和基础触控。内容和渲染分离，证据关系与许可是确定性状态。无需后端、真实法律数据库、云模型、账号、登录或复杂物理模拟。无用户数据采集。第三方素材不自动引入。

如没有既有框架，选最少依赖方案；记录理由和实际运行命令。不要顺手给其他四篇搭共享引擎。

## 任务顺序

先做状态与两条资料链 → 连通全部场景 → 实现时间控制与证据交互 → 完成十秒动作与两个保存 → 添加存档和无障碍 → 运行测试并记录。

## 验收清单

- [ ] 完整流程可达 M08，证据不足时具体提示缺少什么，不静默卡住。
- [ ] 观察节点显示一致的时间和来源；工具不读取人物思想。
- [ ] 唐雯身份只在她主动披露后显示；早期文本不谎称她不知道报告。
- [ ] 前期责任与当晚减灾资料都能进入案件包，不能用一者自动覆盖另一者。
- [ ] 精确退十秒和键盘调整都可到达18:29:50；没有要求精确拖拽到单像素。
- [ ] `caseSubmitted`不自动完成`privateClipSaved`，反之亦然；重入不会重复提交。
- [ ] 私人片段不进入案件附件；案件材料不混进私人文件。
- [ ] 在揭晓前、十秒回溯后、首个导出后恢复存档，都保持正确进度。
- [ ] 静音、关闭打字、键盘控制不损失证据和最后一句话。
- [ ] 至少一次端到端回放和导出隔离的自动状态测试，未执行的测试如实记录。
