# 《给你留一行》demo 验证记录

日期：2026-10-03。范围：本故事目录；隔离分支 `codex/03-a-line-for-you-demo`。这是开发走查与自动化浏览器验证，没有真人参与者，不宣称玩家情感反馈或达到原定 30–40 分钟体验时长。

## 实际环境与命令

Node.js 24.19.0、npm 11.9.0、Vite 7.3.6，Linux 系统 Chromium `/usr/bin/chromium`，Playwright。依赖通过 npm 安装；当前环境网络访问和本机端口监听需要工具的 network 权限。没有使用外部美术、在线模型、账户、后端或公共部署。

在 `03-a-line-for-you/demo/` 实际执行：

| 命令 | 实际结果 |
| --- | --- |
| `npm install` | 成功，产生本目录 lockfile；最初沙箱代理连接 EPERM，启用允许的网络权限后成功 |
| `npm run typecheck` | 通过 |
| `npm run build` | 通过；生成约 84 KB 的本地生产包，未提交 dist |
| `npm test` | 27 项通过，0 失败；18 个早期组合 × 2 种周淮小修改 × 3 个固定末句 = 108 个完整最终态，以及独立留白测试 |

## 场景与交互覆盖

| 场景 | 实际操作 |
| --- | --- |
| P01 现在 | 六页入托盘；提前翻署名；未收纸页也可实际拿起并翻到背面，记录 front/back |
| P02 十二年前 | 接水盆移到滴水下方；三雨句数据覆盖，A 数数、B 就是雨、触控筛米；不同回应与真实原句 |
| P03 现在 | 标注共同对话出处；查看与重复暂存诗云候选；保留原稿 |
| P04 七年前 | 比较三修订，决定「夜风 → 晚风」，亲手标记采用；刷新后保留决定 |
| P05 一年前 | 椅子试放书桌边；原位／斜放；记录普通回信提醒，回到今天形成最终贡献 |
| P06 现在 | 错序不得拼接；逐步提示；真实逐格移动六页；来源翻背核对；拼接后排序锁定；封底签名 |
| P07 今天 | 三个固定末句来自本轮实际椅子、雨声或修订；也可暂留空白；保存决定 |
| P08 保存与尾声 | 玩家确认共同作者；保存后观察窗、书桌、椅子、杯子，重读手稿；刷新继续；重开需确认 |

A 的实际组合：`rain_count / word_wait / chair_window`，保留「夜风」，末句「窗边的椅子，我还没有搬。」。B 的实际组合：`rain_plain / word_keep / chair_angled`，保留「夜风」，最后留白。两者的回收逐字来自各自真实贡献。自动化按机器速度操作；测试耗时不等同于读完故事的游玩时长。

## 额外验证与修复

- 单测覆盖重复提交防重、无效动作不跳关、纸页越界与错误排序、引用读取不修改原状态；损坏／自相矛盾／伪造后期存档均明确恢复。修复了损坏后期存档排序重建可能无限循环的问题，重建循环有界。
- 重开后雨、词、椅子、贡献、署名和确认清空；使用另一个故事命名空间的 sentinel 验证它保持原值，没有清除其他项目存档。
- 真实生产浏览器监测 console error、pageerror、HTTP 失败、requestfailed、外部请求：均为空。修复了 favicon 404，使用原创内嵌图标。
- 检查 1280×900 桌面和 390×844 窄屏。窄屏整条 B 路线与放大纸页没有横向溢出；另做真实 hasTouch + tap。原创房间包括窗、雨、盆、椅子、桌面纸页、杯子、书架、植物、周淮与小序机械底座。
- 修复了雨页标签、排序提示与页源错位；P04／P05 不再出现雨线或错误雨声；跨场景观察文字清理；椅子预览与当前姿态一致。
- 修复了提前署名的阶段回应、作者确认前误说「收到」、候选点击后面板自动收起、纸页翻背与放大后的滚动和焦点跳回。放大 19 → 26 px；减弱动态取消雨线动画。

## 未验证事项与已知限制

- 未做真人叙事试玩，不能判断情绪体验、自然阅读时长或是否达成原始 30–40 分钟目标；目前是较紧凑的完整 demo。
- 验收浏览器为 Chromium；Firefox、WebKit、实际手机硬件和真实读屏器未验证。键盘、基础触控模拟与可访问语义已检查。
- 合成雨声的开关、无异常与静音状态已验；音质与主观听感未由真人评估。没有配音。
- 本地存档依赖浏览器 localStorage；禁用存储时提示无法保存，但关闭页面可能失去进度。没有云同步。
- 未实施自由输入，没有文学评分或无限生成。尾声可自行停留，没有自动计时强制结束。

下一轮最重要的三个改进：开展不透露反转的真人试玩，确认玩家能认出自己的原句；评估相处段落与纸页操作的节奏；在真实手机和读屏器上验证翻背、放大与焦点提示。
