# 给你留一行

> v0.1 · 2026-10-03 · 开发剧透文档 · 平行改编构想

背景起点：《诗云》。本篇另设人类已能检索诗云、AI具有成熟理解和创作能力的生活环境；不把这些新增规则冒充原著事实。

**一句话：你是一名 AI，以为自己在替故去的诗人完成遗作，最后发现，他早已为你留下共同作者的位置。**

## 人物

- **小序，玩家角色**：具备自主感受与选择能力的家用 AI，连接一台室内移动底座和桌面操作臂。开场即公开身份，不做『原来你不是人』反转。
- **周淮**：与你长期相伴的诗人。会写得不好，会听取你的反对；不把你当必须通过灵魂测试的工具。
- **沈青**：负责整理出版材料的编辑。不是反AI的反派；她提出的单作者登记只是尚未核实的工作假设。

## 核心

玩家前半段选择的雨声比喻、改过的字与共同约定的摆设，在后半段以同样的文本和物件重新出现。小序记得那些对话，不是假装失忆；新的信息是诗人如何把这些共同经历编排为共同作品，以及他已写下的署名。

最后的空白不是一个待预测的标准答案，而是一行允许小序自己决定说什么、何时说的话。可以写普通句子，也可以暂时留白。结尾必须由玩家确认自己的作者位置，不要求证明机器胜过人类。

阅读 [SCRIPT.md](SCRIPT.md)、[DESIGN.md](DESIGN.md)、[CODEX_TASK.md](CODEX_TASK.md)。建议优先做30–40分钟闭环 demo，再评估是否扩展为90–120分钟短篇。内容提示：失去长期同伴与日常哀伤，无暴力画面。
