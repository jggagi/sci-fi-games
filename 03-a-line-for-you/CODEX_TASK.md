# Codex 任务｜《给你留一行》共同创作叙事 demo

## 执行要求

先读根目录 `AGENTS.md`，再完整读本目录 `README.md`、`SCRIPT.md`、`DESIGN.md`。只处理这一篇。检查既有实现；没有则在 `demo/`创建独立、轻量、可在本地浏览器打开的2D叙事体验。实现 P01–P08，不只输出方案或一页梗概。

## 第一版必须有

1. 一间房在不同日期的可辨变化，当前档案与过去经历的明确切换。
2. 三个雨声选项、三个词语修订选项、两个椅子位置。选择不评分，分别保存为稳定状态。
3. 来源可追踪的手稿拼接：后半段逐字复用本轮真实选择，修改记录也一致。
4. 允许提前看到署名的合法路径；后续根据`coauthorSeen`调整对白，不强行装失忆。
5. 最后一行的三类行为：固定文本、本地自由输入（可选实施）、暂留空白。固定文本与留白足以完整通关。
6. 玩家手动确认作者栏，并能在结尾后继续看房间和手稿。

诗云候选全部用作者预写内容，不接任何云模型。不需要真正枚举诗歌空间、做语义检索、OCR或生成手写图。不要使用第三方诗歌作为占位内容。

## 实施顺序

先把选择→贡献→手稿的确定性数据链做对，再连通剧情，再做纸页／窗边／椅子交互，最后加演出、存档、键盘与触控。不得先做复杂聊天系统来替代编排。

若启用自由文本，将其当不可信显示文本：长度限制、以纯文本渲染、本地存储、不执行HTML、不作为提示词发到外部。无需先要求用户提供API Key。

## 验收

- [ ] 玩家从开场知道小序是AI，剧情不依赖身份或失忆反转。
- [ ] 三种雨声与三种词语修订在相应手稿中逐字对应；不串入其他存档的选择。
- [ ] 两种椅子姿态在过去、现在与最后一句均一致。
- [ ] 查看／暂存诗云候选不会破坏原稿和真实历史。
- [ ] 提前看署名与按默认顺序看署名都能完成，对白不自相矛盾。
- [ ] 填写与留白两条路径均能确认作者并进入尾声，无好坏结局排名。
- [ ] 存档恢复后保留贡献、修订、纸页顺序和最终作者状态。
- [ ] 自由文本如实现，测试尖括号、长字符串和换行，不执行注入内容。
- [ ] 静音与键盘全程可用，雨声有文字反馈，手稿可放大阅读。
- [ ] 至少两条完整组合端到端回放，全部选择映射有数据级测试；未执行检查如实标明。

## 交付

提供实现、内容数据、测试、`demo/README.md`（准确启动命令）及`PLAYTEST.md`（实际观察、未验证项、下一轮问题）。无需承诺达成目标体验时长，先记录真实试玩。

可微调对白与场景转场；修改共同作者、贡献回放、AI自主性、留白有效性等核心，要先写改稿提案，不能直接改成『AI其实是逝者上传人格』或『一切都是模拟治疗』。
