# sci-fi-games

五个以刘慈欣小说设定为起点的剧情向独立游戏开发项目。当前版本为 **v0.1 分场剧本与 demo 交接文档**，不是已经实现的游戏。

创作目标：让科幻改变人物之间能做与不能做的事情；让结尾重新解释玩家亲手做过的动作，而不只是公布一段悲惨身世。重视具体关系、人物自主权、可回看的伏笔与反转后的可玩余韵。不以削弱 AI、强行死亡或道德评分来制造感动。

> **剧透提示：** 本仓库是开发资料，包含完整反转、结局与测试说明。新增角色、对白、情节与实施规则均为平行改编构想，不是原著内容。《去月球》仅为情感体验参考，不复用其角色、文本、音乐、素材或具体谜底。

## 五个项目

| 子目录 | 暂定标题 | 背景起点 | 关系与情感核心 | 首个 demo 建议体验长度 |
| --- | --- | --- | --- | --- |
| [01-tomorrow-again](01-tomorrow-again/README.md) | 明天还去吗 | 《带上她的眼睛》 | 你带她看世界，她却一直在看你 | 25–35 分钟 |
| [02-ten-seconds-earlier](02-ten-seconds-earlier/README.md) | 再往前十秒 | 《镜子》 | 揭发父亲之后，仍想保留一段叫他爸爸的记忆 | 25–35 分钟 |
| [03-a-line-for-you](03-a-line-for-you/README.md) | 给你留一行 | 《诗云》 | 你以为在替他完成遗作，其实他给你留了共同作者的位置 | 30–40 分钟 |
| [04-the-next-morning](04-the-next-morning/README.md) | 第二天早上 | 《朝闻道》 | 他不是没能去；他曾经主动回来，与你一起面对第二天 | 30–40 分钟 |
| [05-saturday-departure](05-saturday-departure/README.md) | 星期六出发 | 《中国太阳》 | 父亲记得你的梦想，但不要求你兑现童年的自己 | 30–40 分钟 |

上述时间是目标游玩长度，不是制作工期，也不是已经实测的结果。各篇互为独立世界，不建立共享宇宙。

## 每个子目录的文档

- `README.md`：故事定位、人物、情感锚点与阅读顺序。
- `SCRIPT.md`：含结局的分场剧本初稿，包含舞台动作、玩家操作、实际对白、分支与收束。
- `DESIGN.md`：伏笔回收表、状态与因果、交互、美术声音范围、叙事风险和试玩问题。
- `CODEX_TASK.md`：可以直接交给 Codex 的独立 demo 实施任务，明确范围、状态、验收与禁止扩张项。

先读根目录 [AGENTS.md](AGENTS.md)，再进入目标项目。文档是可打磨的 v0.1 创作基线，不是不可修改的终稿；核心反转、关系伦理或结局改动，应先单列提案，不能在实现时无声替换。

## 下一步

优先逐篇制作包含完整情感闭环的灰盒 demo，而不是同时搭建五套大工程。每篇先证明“玩家是否在意这个人、是否理解前面的动作、揭晓之后是否愿意再做一次”，再投入美术与扩展篇幅。

默认可在本地浏览器体验、无需账号和云服务；每篇独立运行，内容与呈现逻辑分离。当前不选定统一引擎，不建立共享基础设施。具体实施以各篇任务文件为准。
