# Codex 任务｜《第二天早上》实验与关系叙事 demo

## 执行

先读根目录`AGENTS.md`与本目录全部三份叙事文档。仅在本项目中实现，缺实现时创建`demo/`。交付完整浏览器2D灰盒体验，从D01到两种D08均能到达。不要只交付一套选择题或一段视觉小说开头。

## 最小实现

1. 单一实验规则函数：首脉冲输出1；次脉冲在间隔<3时输出2，否则1；与端口无关，每轮重置。使用表格测试所有左右组合及间隔1–4。
2. 可执行的两次输入、可复查记录、至少一次提出假设和一次用反例修订。清楚标明虚构实验，避免现实科学断言。
3. 同一实验室的年代切换、固定人物、关键普通对白和撤回回执。
4. 玩家直问与程砚实际回答的对话，不省略『有过后悔』『不需要替我证明』。
5. 明确交换条件、独立的最终确认、两条真实可玩尾声。没有测试得分决定生死，没有暗中复活漏洞。
6. 本地存档、重新开始、章节恢复、无障碍输入与静态脉冲显示。

## 技术范围

默认最小依赖浏览器实现。内容数据、实验模型、剧情状态与渲染分离。无后端、云AI、真实科学仿真、用户身体数据或真人摄像头。实验不是计时挑战，也不需要高频闪烁。不要为五篇预建通用科研引擎。

实施顺序：实验纯函数及测试 → 场景状态与全流程 → 操作面板 → 回执及两条尾声 → 存档和可访问性 → 实际回放。

## 验收

- [ ] 全部端口组合与间隔1–4给出文档规定输出，文案和模型不矛盾。
- [ ] 玩家可用控制变量区分解释；错误不会卡死，提示不抢先公布第一次发现。
- [ ] 最终问题与已完成的局部规则区分，不伪称解答了现实宇宙问题。
- [ ] 档案与既有对白一致：程砚没有伪称落选，林予有机会质问没说清楚。
- [ ] 资料交接区分事实、猜想与未完成项，两种选择都能完成交接。
- [ ] 选择退出后仍然实验；选择交换后切换为程砚，无法填入未传回的答案。
- [ ] 两种结局都有玩家操作，没有一种仅显示『待实现』；不存在道德胜负标签。
- [ ] 结局确认前、确认后与尾声存档恢复一致，重复进入不更改已确认决定。
- [ ] 静态显示、静音、键盘可完成全部操作，不以闪烁或音高作为唯一线索。
- [ ] 两条结局各至少一次端到端回放，实验规则有自动测试，未运行的检查如实列明。

交付`demo/README.md`、内容与实验数据、最小测试及`PLAYTEST.md`。目标长度不是已验证承诺。任何把一条路改成官方正确答案、新增死亡操作、取消研究欲望或使用复活救援的修改，先写独立改稿提案，不直接实施。
