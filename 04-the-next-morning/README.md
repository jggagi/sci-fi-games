# 第二天早上

> v0.1 · 2026-10-03 · 开发剧透文档 · 平行改编构想

背景起点：《朝闻道》。本篇新增排险者多年后再次开放机会、两位研究者相伴的一生与一套虚构实验。不是原作事件续写的事实说明。

**一句话：你一直以为伴侣当年没能获得答案，后来才接受普通生活；直到今天，你发现，他获得过资格，也亲自决定回来。**

## 人物

- **林予，玩家角色**：年长研究者，仍然对一个基础问题怀有强烈好奇。不是被生活治愈后就不再需要研究的人。
- **程砚**：她的长期伴侣与研究合作者。年轻时获得过以生命交换答案的资格，主动退出。他会后悔，也会继续追问，不是从未动摇的完美奉献者。
- **沈翎**：接手部分实验的年轻研究员，只在少量场景出现，让研究具有真实的交接对象，而非一句『精神永存』。

## 核心情绪

先让玩家真的因为一个小实验产生『我想知道为什么』，再让『明天换个办法，再试一次』从普通研究习惯，变成一个人曾经主动选择回来的理由。

退出资格、留在生活中不授予道德奖章；选择答案也不被塑造成高于他人的科学家殉道。伴侣过去的决定不是要求玩家偿还的债。

本篇有两条明确结局，首个 demo 均需有真实收束：继续面对第二天，或进入答案交换后的留存者视角。避免具体死亡过程与视觉美化。
