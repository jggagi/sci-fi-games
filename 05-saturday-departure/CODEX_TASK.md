# Codex 任务｜《星期六出发》父子与自主出发 demo

## 执行要求

完整阅读根目录`AGENTS.md`及本目录`README.md`、`SCRIPT.md`、`DESIGN.md`。仅在本项目内工作，缺实现时创建独立`demo/`。实现可运行的轻量浏览器2D短篇，不只做一段宇宙片头或一张选目的地的页面。

## 实施内容

1. 四组有限场景、两三个确定性的检查操作、自动维护报告、真实返程票和空白申请表。
2. 旧画逐步展开；图中文字早已存在，角色对白不主动撒谎。支持提前推断后的自然回应。
3. 一个短小可玩的童年纸箱灯场景，与成年检修灯、结尾舱内灯呼应。
4. 旧图与成年计划独立存储，成年计划由玩家重新填写并确认。
5. 长程、近程、暂不加入三条完整尾声，均能保留旧图；父亲不以失望或病情惩罚任何选择。
6. 中文对话、键鼠与基础触控、字幕、可关闭视差、本地存档与重开确认。

## 技术约束

默认本地、离线内容、不需要账号、真实飞行模拟、后端或云AI。检修与资格条件都是剧情内预写状态，不接实际航天系统。不要引入开放星图、经济经营、战斗或通用星舰建造器。

没有既有框架时选择最小依赖方案并记录理由。先确定状态和所有尾声，再做背景、演出和有限动画。内容与渲染分离，不把长篇对白散落在组件里。

## 验收清单

- [ ] S01–S08可走通，三种计划均有真实尾声而非『待实现』。
- [ ] 自动维护能正常工作，故事不依赖机器出错证明父亲价值。
- [ ] 返程票、空白表与父亲对白从前期就相互一致，没有代签或偷偷预订不可拒绝行程。
- [ ] 旧图从已有物件展开，不是揭晓时新发放的证据。
- [ ] 两种童年目的地不限制成年三选一，至少测试全部六种组合的状态映射。
- [ ] 三种结局都允许拿走旧图，没有优劣结局编号或好感条。
- [ ] 远航分支显示明确已选航段，不瞬间完成星际旅行；近程分支不是失败字幕。
- [ ] 暂不加入分支父亲不失望施压，项目由其他人继续，玩家不会被自动创建未来承诺。
- [ ] 确认前、确认后和不同尾声的本地恢复正确；重复点击不改变已确认计划。
- [ ] 折纸、接线、填写计划可用键盘完成，静音和减弱动态不丢信息。
- [ ] 三条结局至少各一次完整回放，关键状态有测试；未执行检查如实标注。

## 交付

提供独立demo、叙事数据、最小测试、`demo/README.md`与`PLAYTEST.md`。如实记录体验长度和已知不足。可删重复对白、微调检修难度；改变父亲自主回家、孩子有权不去、无隐瞒绝症、旧图与新计划独立等锚点，先写`STORY_PROPOSALS.md`，不直接替换。
