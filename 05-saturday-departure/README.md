# 星期六出发

> v0.1 · 2026-10-03 · 开发剧透文档 · 平行改编构想

背景起点：《中国太阳》。本篇新增退休维护员、成年子女、旧航线册与已经获得项目支持的试航计划，不作为原著人物与事件的复述。

**一句话：你以为回来是替父亲完成他未实现的远航梦想，最后发现，他只是想让你知道，你小时候想去的地方，现在真的有了出发的机会。**

## 人物

- **陈遥，玩家角色**：航天工程师，具备本案虚构项目所需的飞行资质。很会完成工作，却习惯把自己的愿望放到以后。他不必因为结尾一次行动就辞职或重写全部人生。
- **陈建平**：父亲，轨道镜面的老维护员，即将退休。珍惜自己的工作，也真心想回家；没有隐瞒绝症，不以牺牲半生换取孩子听话。
- **许棠**：试航项目协调员。她直接向陈遥说明参与条件、可选航段与撤回方式。父亲没有代签或替他占据必须兑现的舱位。

## 关键情感锚点

旧航线不是父亲年轻时的计划，而是玩家小时候画的：『爸爸修船』『我当船长』『星期六出发』。父亲保留它，不意味着孩子永远欠一个承诺。

必须保留：『现在不想去了，也行。』『我就是觉得，船还能开的时候，应该告诉你一声。』最终目的地由成年玩家重新填写，可远航、近程试航或暂不加入。父亲回家也不是放弃梦想的失败结局。

阅读 [SCRIPT.md](SCRIPT.md)、[DESIGN.md](DESIGN.md)、[CODEX_TASK.md](CODEX_TASK.md)。首个完整情感 demo 30–40分钟；扩展短篇暂定90–120分钟，均需试玩验证。基调是带着一点酸楚的明亮，不靠葬礼或来不及说出口制造结尾。
