## 其他明确要求

- 检修是两项设备检查和最后的固定点核验：报告 mrad / °C、P2 指示灯、S06 的 60 kg / 80 kg 载荷及锁止标识。工具交接是关系动作，三项验收已交付后留在余韵文档。
- 父亲退休不是等待子女的占位：早期便笺有新修道路、社区修理角、收音机旋钮与窗台种葱。长 / 近程在下一放行窗口开始，父亲已经按票回家；不加入同返程舱。
- 提前推断用同场稳定 ID 的自然回应；S05_TRUTH 会说「我刚才猜到了」，不要求装作惊讶。
- 轨道设施、生活工作台、观景窗、纸箱与三种尾声均为原创 SVG。检修灯、纸箱手电、舱内灯由实际操作状态改变，同一暖色光形成呼应。
- 原创合成声经显式取消静音才开始，通话信息均有字幕；自由文本经过 HTML 转义，作为纯文本保存和显示。
- 存档唯一命名空间：`sci-fi-games:05-saturday-departure:v1`。损坏原档保留到明确确认恢复，重开可取消，不清空其他项目。缺存储、配额不足有提示。
- `dev`、`build`、`preview`、`typecheck`、`test`、`test:e2e` 全部提供，默认端口 5175 可由 CLI 覆盖；无后端、账号、云 AI 或运行时外网资源。

- 首轮 `npm run test:e2e`：4 / 4 通过，生产页面真实从新游戏通关。长程鼠标、近程纯键盘、不加入 390 × 844 触控、损坏恢复与重开。总计约 48 秒是自动执行时长。

## 尚未验证与体验边界

- 没有外部真人试玩，没有验证自然阅读长度、情绪效果或玩家对选择压力的主观感受。
- 浏览器实测为 Chromium；未实测 Safari、Firefox、真实手机硬件和屏幕阅读器。原生控件及字幕提供基础，但不宣称完整辅助技术认证。
- 环境声为程序合成，非配音或大型音乐演出；没有通过人的听觉检查宣称艺术效果。
- 有限探索按场景顺序推进，不提供自由飞行或开放空间。长程只呈现第一段开始，余下转移、观测及返航按文本条件说明，没有瞬间星际抵达。
- 本人填写的目的地是对所选具体项目安排的记录；不允许文字输入创建新的星系、航行模拟或额外任务。

下一轮最重要的三项：招募不提前读脚本的真实试玩者记录误解与选择压力；按实际阅读停留调整检修与真相对话节奏；补充真实移动设备及屏幕阅读器走查。均不以删除近程或不加入来缩减范围。
