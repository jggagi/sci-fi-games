# 明天还去吗 · 浏览器 demo

可独立试玩的第一人称点选短篇，包含 T01–T08、三日行程、相册发现、镜前肖像和断线后的可玩尾声。画面为本项目原创 SVG；人物固定虚构，没有真实相机、麦克风、上传、后端或网络服务。制作与发行授权状态遵循上级故事文档。

## 安装与运行

使用 Node.js 24 或更新版本与 npm。所有依赖、配置、存档逻辑与测试均在本目录。

```bash
cd 01-tomorrow-again/demo
npm ci
npm run dev
```

在浏览器打开 http://localhost:5171/。默认端口 5171，端口占用时明确报错；可用 `npm run dev -- --port 5173` 或 `PORT=5173 npm run dev` 覆盖。

生产构建与本机预览：

```bash
npm run build
npm run preview
```

同样打开 http://localhost:5171/；先停止占用该端口的开发服务。预览可用 `--port` 或 `PORT` 覆盖。生成的 `dist/` 是可用任意本地静态 HTTP 服务托管的独立资源，构建后运行不依赖外网；不要通过 `file://` 直接双击入口。没有公共部署。

## 操作

- 鼠标或触控点选景物热点、对话选项和工具。热点下方有同等文字按钮，无需精确拖拽或快速反应。
- 键盘用 Tab / Shift+Tab 切换焦点，Enter 或空格操作按钮，Esc 关闭工具。弹窗限制焦点在内部，关闭后返回原控件。
- 顶部工具可随时打开相册、路线和设置。早期共享照片已经可以看，不封锁线索。
- 相册用“顾远收藏 / 闻夏标记 / 全部画面”筛选，点击照片放大，用“往前移 / 往后移”重排。第三日整理需要实际查看桌面中央、下坡之前、栏杆上的暮色三张旧图，并重排一张。
- 湖岸和尾声使用同一个摄影工具：先选构图，再保存。同一构图重复保存不会复制照片；不同湖景与天色构图各有自己的记录。
- 默认整句字幕立即显示、静音。设置可启用打字效果、关闭它或减弱动态；打字期间也能立即操作。取消静音后，只在用户操作后播放原创短提示音。
- 窗口关闭后仍可摄影、查看相册、给明日写路线或留空，最后由你点击“结束今天的行程”。结束后相册仍可打开。

进度随动作自动保存。刷新后在标题页选择“继续行程”；“重新开始”需要确认。命名空间为 `sci-fi-games:01-tomorrow-again:v1`，只覆盖本故事记录。损坏存档保留到确认恢复，提示重新开始；浏览器拒绝本地存储时会显示警告，此时可继续玩，但刷新会失去进度。不同端口或浏览器属于不同本地存档来源。

## 验证

```bash
npm run typecheck
npm test
npm run test:e2e
```

`test:e2e` 自动先构建生产版本，再启动本机 preview，使用真实 Chromium 回放。它需要 5171 未被占用，可用 `E2E_PORT=5172 npm run test:e2e` 换端口。默认优先使用 `/usr/bin/chromium`；其他平台首次运行可安装测试浏览器：

```bash
npx playwright install chromium
npm run test:e2e
```

已有浏览器可用 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e` 指定。已有**本机测试服务**时，可用 `E2E_EXTERNAL_SERVER=1`，此模式不保证生产构建；正式验收使用默认的生产服务模式。受限制的执行沙箱须允许本机端口与浏览器进程。依赖与浏览器安装需要网络，试玩无需网络。

状态测试走实际 reducer 路径，覆盖早餐 × 头发 × 路线的八种组合、来源一致性、重复操作、恢复和损坏检测。UI 测试从新游戏真实点击 / Tab / Enter / 触控完成，不注入后期存档或跳关：桌面热粥＋整理、桌面键盘面饼＋不整理、窄屏触控面饼＋整理，以及独立的存档恢复 / 重开检查。截图自动写到 `tests/screenshots/`；失败 trace 与报告位于忽略提交的 `test-results/`。

完整验证记录、局限与截图见 [PLAYTEST.md](../PLAYTEST.md)。目标长度参考 25–35 分钟；未进行不知情真人试玩，不宣称已达到时长或情绪目标。

## 实现索引

| 文件 | 职责 |
| --- | --- |
| `src/content.ts` | 稳定场景、对白、选择与节点图；唯一文案来源 |
| `src/model.ts` | 显式状态机、动作校验、照片快照、保存先后顺序、存档验证 |
| `src/art.ts` | 原创 SVG 场景与照片；照片只读取当时快照 |
| `src/main.ts` / `src/style.css` | DOM 字幕、工具、可访问控件、焦点与响应式布局 |
| `tests/model.test.ts` / `tests/journey.spec.ts` | 状态路线与真实生产 UI 回放 |

使用 Vite + TypeScript 与原生 DOM / SVG，无运行时第三方依赖。Playwright、TypeScript、tsx 与 Node 类型仅用于开发和验证。不建立共享引擎或修改仓库根目录配置。
