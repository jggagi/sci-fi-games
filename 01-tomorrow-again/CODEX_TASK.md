# Codex 任务｜《明天还去吗》完整情感闭环 demo

## 给 Codex 的执行指令

先读根目录 `AGENTS.md`，再完整读本目录 `README.md`、`SCRIPT.md`、`DESIGN.md`。只在本项目内工作。先检查是否已有实现；没有则创建 `demo/`，默认轻量浏览器 2D点选体验。不要只返回架构建议；实现可运行、可从开头走到尾声的 demo。不要在这个任务中同时开发其他四篇。

## 范围

按 SCRIPT 的 T01–T08浓缩实施。核心不是自由步行，而是可操作的视点、餐具、观测点、照片筛选、镜面与保存。可省掉凳子／小狗支线，不可省掉早餐之手、山坡影子、湖边反射、相册重排、镜前肖像与断线后的可玩余韵。

首次没有代码时，选择最少依赖的本地浏览器实现，记录选择理由与实际启动命令。无需后台、登录、云端 AI、真实相机、麦克风或文件上传。所有角色数据为固定虚构内容。

## 实施顺序

1. 场景与内容数据：建立稳定场景 ID、对白 ID、热点、显式进入条件和退出条件；让内容与渲染分离。写入 `DESIGN.md`定义的最小状态。
2. 可走通灰盒：先连通全部必做场景，加入键盘、鼠标和基础触控。不先做复杂菜单、共享引擎或美术生成服务。
3. 真实行动回放：用 `frameId`记录实际发生的构图与变体；T06复用同一记录。实现两种收藏筛选，早期允许查看已存在的记录，不伪锁相册。
4. 关键演出：T07第一次完整显示固定主角；两种头发变体；确认保存后才关闭信道。尾声复用摄影操作，玩家自主退出。
5. 存档与验证：本地带版本存档、继续、重新开始确认；开发跳转仅开发模式可用，不在玩家界面泄露剧情。
6. 写 `demo/README.md`和 `PLAYTEST.md`，说明运行、内容覆盖、已知不足、实测结果与未执行检查。

## 必验收

- [ ] 新游戏完整走到 T08，无假按钮、无无限等待、无卡死。
- [ ] 两种早餐会在照片与回忆中准确对应，不出现没做过的善行。
- [ ] 至少三张反转证据由玩家前面真正触发；相册排序不改原图。
- [ ] 玩家早期打开共享记录不会破坏流程，也不出现自动剧透说明。
- [ ] 镜前没有实际摄像头权限请求，也不读取玩家照片。
- [ ] 整理／不整理头发均可完成；保存确认先于断线；断线不显示闻夏死亡。
- [ ] 在 T04、T06、T07保存并恢复，画面、动作变体与对话进度保持一致；重复进入不重复发放照片。
- [ ] 键盘完成全流程，文字无溢出；静音和减弱动态不丢失关键信息。
- [ ] 至少一种参考路线做浏览器端完整回放；另一个早餐和头发组合做状态测试。

未能实际运行的测试写『未执行』，不能写已通过。目标游玩长度只是设计目标，未试玩不得宣称命中。

## 交付与修改边界

交付自包含 demo、内容数据、最小测试、运行文档与一页试玩观察。可润色重复台词和移动节奏；若需要改变保存同意、失联不等于死亡、镜前初见或核心回放，先写 `STORY_PROPOSALS.md`解释问题与替代方案，不直接改掉。不要靠新增死亡、绝症、隐藏亲属身份或拯救分支增强情绪。
