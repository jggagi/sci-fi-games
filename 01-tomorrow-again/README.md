# 明天还去吗

> v0.1 · 2026-10-03 · 开发剧透文档 · 平行改编构想

背景起点：《带上她的眼睛》。新增角色、对白、通信安排与旅行路线均为本项目设定，不作为原著梗概。

**一句话：你受托带一个无法回到地表的人看世界，最后发现，她保存得最多的不是风景，而是你在世界上生活的痕迹。**

## 人物与体验

- **顾远，玩家角色**：地表测绘外勤员，习惯把关心表达成把事情做好。并非等待女主治愈的创伤谜题；没有需要结尾揭晓的悲惨身世。
- **闻夏**：困在深层地航舱的工程师。专业、偶尔急躁、有生活趣味。她有自己的工作和之后的日子，不只是一个等待告别的人。

核心关系是相互照顾，不强制命名为恋爱。她无法回到地表是开场已知事实；信道结束也不等于生命结束。

## 必须保留的情感锚点

1. 玩家确实带她去过至少三个地方，并留下可辨认的行动痕迹。
2. 她保存照片的行为早已可见，不是结尾凭空生成的秘密相册。
3. 相册重排后，玩家发现自己也在被认真看见。
4. 玩家走到镜子前，第一次完整看见固定主角的脸。
5. 她只说普通的话：『原来你长这样。』『头发左边翘起来了。』
6. 最后一张照片在信道关闭前获得『已保存』确认。她仍然活着。

## 文件

按 [SCRIPT.md](SCRIPT.md) → [DESIGN.md](DESIGN.md) → [CODEX_TASK.md](CODEX_TASK.md) 阅读。完整稿定位为约 60–90 分钟短篇的初稿；首个 demo 采用 25–35 分钟浓缩闭环，均待试玩验证。

第一版只需要五组可复用的 2D 场景、对白、音景、热点、照片与一次镜面交互。不要先做自由 3D 步行、真实相机接入或全套生存模拟。

## 独立试玩实现

`demo/` 已提供 Vite + TypeScript 浏览器实现，包含 T01–T08 和自主结束的可玩尾声。安装、开发、生产预览与测试命令见 [demo/README.md](demo/README.md)，逐项验证和局限见 [PLAYTEST.md](PLAYTEST.md)。以上体验长度仍是目标，不能视为实测结论。
